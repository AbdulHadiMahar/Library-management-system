# 📚 Library Management System

A simple **Library Management System** built with Python.

This beginner-friendly project allows users to manage books in a library, including adding new books, viewing available books, checking book details, removing books, borrowing books, and returning borrowed books.

The program uses text files to save the library data so that books remain available after restarting the program.

## ✨ Features

- 📖 View all available books
- ➕ Add a new book
- 🔍 View details of a particular book
- 🗑️ Remove a book from the library
- 📤 Borrow a book
- 📥 Return a borrowed book
- 💾 Save library data to text files
- 📂 Load saved books when the program starts
- 🚫 Prevent duplicate books from being added

## 🛠️ Technologies Used

- Python 3
- `os` module
- Object-Oriented Programming (OOP)
- Classes and objects
- Class methods
- Lists
- File handling
- `match-case`
- Basic input validation
